# Phenotech Marketer

Marketing workspace for [Phenotech](https://phenotech.mehro.ch), a sourced research atlas of rare diseases.
Claude drafts here and the founder approves and publishes. Start with [CLAUDE.md](CLAUDE.md) and [PLAN.md](PLAN.md).

| Folder | What |
|---|---|
| `brand/` | Brand guide, logo, image sources |
| `linkedin/` | Company page fields, setup checklist, launch posts, images |
| `tools/` | Claims checker (`node tools/check-claims.mjs`), image rendering, screenshots |
